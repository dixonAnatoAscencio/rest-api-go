# 📦 REST API con Go y Gin

Esta es una REST API desarrollada en Go utilizando el framework [Gin](https://github.com/gin-gonic/gin). La API proporciona endpoints básicos para manejar recursos (por ejemplo: usuarios, productos, tareas, etc.), ideal para proyectos backend ligeros y eficientes.

---

## 🚀 Características

- 🌐 API RESTful con rutas limpias
- 🔐 Middleware para manejo de errores, logs y CORS
- 📄 Respuestas en formato JSON
- 🧪 Pruebas básicas con `httptest` (opcional)
- 📦 Gestión de dependencias con Go Modules

---

## 🛠️ Tecnologías

- [Go](https://golang.org/)
- [Gin Gonic](https://github.com/gin-gonic/gin)
- (Opcional) [GORM](https://gorm.io/) para ORM
- (Opcional) [Swagger](https://github.com/swaggo/swag) para documentación de la API
